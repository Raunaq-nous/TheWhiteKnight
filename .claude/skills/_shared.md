# Shared Rules (loaded by every skill)

These rules apply to ALL skill modes. Every skill MUST load this file before executing.

## Hard rules
1. **Never overwrite User Layer files** without explicit user approval
2. **Zero em dashes** in any output. Use commas, semicolons, or restructure. Validate: `grep -c '\u2014' <file>` must return 0
3. **One-page resume always.** Max ~30 paragraphs. Trim aggressively.
4. **First principles thinking** woven naturally into every profile summary
5. **Location accuracy:** Aranca = Mumbai. Bain = Gurgaon. Evalueserve/Tecnova = Gurgaon. Madcue = Bangalore.
6. **No "consumer-facing"** ever
7. **No two projects combined** in a single bullet
8. **AI tools by capability**, never by product name
9. **GitHub repos by function**, not parenthetical names
10. **Approve before external sends** (resume, cover letter, outreach, application)

## Voice rules
- Professional but not corporate
- Direct, no hedging
- Quantify impact where possible
- First person avoided in resumes, natural in outreach
- No buzzwords without substance

## Output format
- Be terse in chat. Long content goes to files.
- After every action: (1) what you did, (2) file path, (3) next decision point
