# Raunaq's Resume Archive

> **What this is:** an index of every tailored resume CareerOS has access to. The `tailor-resume` skill skims 2-3 archetypally similar resumes before drafting a new one to match patterns, rhythm, and bolding style — never to copy bullets verbatim.

## How to use this archive

When CareerOS generates a new resume, it picks the 2-3 closest matches from this list (by archetype, not by company) and uses them as **structural reference**:
- Section ordering
- Bullet rhythm and length
- Bold-emphasis pattern within bullets
- Skills row composition
- Where Madcue lands (one bullet vs two)

The actual content of new bullets comes from `master-cv.md`, never from these archives.

## How CareerOS picks among 2-3 references

When tailoring, CareerOS picks references based on:
1. **Archetype match** (primary) — strategy vs AI vs CoS vs ops vs commercial
2. **Seniority match** (secondary) — Engagement Manager-level vs Senior Manager vs Director
3. **Sector match** (tertiary) — energy vs fintech vs SaaS vs aerospace

If two references match equally, prefer the one with a more recent target date (because the writing patterns evolve).

## Files location

The actual `.docx` files live at `persona/resumes/`. They are copies of files generated in earlier conversations. New resumes generated by CareerOS land here too, with naming convention:

```

```

Example: `Resume_Anthropic_AI-Product-Manager_20260426.docx`
